## 🚀 How to Save to GitHub and Deploy on Vercel

### Step 1: Create GitHub Repository
1. Log in to [GitHub](https://github.com).
2. Click **New Repository**.
3. Name it `sopno-fast-food-cafe`.
4. Keep it **Public** and click **Create repository**.

### Step 2: Add Code Files
Create the following 6 files directly in the GitHub repository interface:
- `roles.json`
- `menu.json`
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

### Step 3: Deploy to Vercel
1. Log in to [Vercel](https://vercel.com).
2. Click **Add New...** -> **Project**.
3. Connect your GitHub account and import `sopno-fast-food-cafe`.
4. Click **Deploy**.
